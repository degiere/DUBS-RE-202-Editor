RE-202 PROBE

Six checks against the pedal. Cable the pedal's MIDI OUT back to the computer, run them top to bottom, then copy the results at the bottom.

Ports

1. Does the pedal answer?

Sends an Identity Request, then asks for the system settings.







  
2. Is 20 00 00 00 the memory being played?

  
Set the pedal to MANUAL and press Read. Turn SATURATION on the pedal and press Read again. Then step the pedal to memory 1 and repeat. Each read lists what changed at 20 00 00 00 and in the MANUAL slot.

  
  






  
3. Does a one-byte write change the sound at once?

  
Each button writes one byte. Watch the HEAD lamps and listen.

  
  

  

    

  
  
The pedal changed at once? 

  






  
4. Do system settings apply without a power cycle?

  
Run check 1 first. INPUT shows on the pedal's GUITAR / LINE lamps; Direct Sound off mutes the dry signal.

  
  
  
  
The pedal followed? 

  






  
5. Control changes, both ways

  
The buttons send Echo Vol on the channel above. Then turn any knob on the pedal and press its MEMORY switch: what arrives shows here.

  
  
The echo dropped out and came back? 

  






  
6. Does SysEx get through with Rx Ch OFF?

  
Run check 1 first. Sets Rx Ch to OFF, asks the pedal a question, then sets Rx Ch back. If the pedal stops answering, set its MIDI channel again from the power-on menu.

  
  






  
7. Tap time and the heads

  
Play a single short note into the pedal after each button and count the repeats against a metronome or by ear. Each button loads a sound into the pedal with the tap time on, Intensity at 0 and Echo Vol up, so each playing head is heard once.

Mode 12's four echoes are evenly spaced? 

  
Mode 8 at 400 ms: head 4 arrives at 1.6 s? 

  
After the recall the time is the same? 

  
Repeat Rate changes the time while the tap time is on? 

  






  
8. Where does oscillation start?

  
Pick a mode and tape, play one note, and raise Intensity until the repeats stop dying away. Record the lowest value that runs away.
